# Mainland-China network acceleration (install-time only)
# -------------------------------------------------------
# The variables below are read by the INSTALLER scripts, not by the running
# backend — put them in the environment of the install command (or in a shell
# export), not in the systemd unit. All of them are opt-in: leaving them unset
# keeps the default install behaviour exactly as before.
#
# Docs: docs/zh/CHINA-NETWORK.md  ·  Script: scripts/cn-mirrors.sh
#
# Switch the host's system package mirrors (and common dev-tool mirrors) to a
# mainland-China mirror BEFORE runtime dependencies are installed.
# Values: auto (default, picks by reachability, TUNA first), tuna, ustc,
#         aliyun, tencent, huawei.
# Example: sudo WEBKVM_CN_MIRRORS=auto bash /tmp/webkvm-install.sh
#WEBKVM_CN_MIRRORS=auto
#
# Comma-separated components for the mirror switch.
# Default: os,pip,npm,go,docker  (optional: cargo,git)
#WEBKVM_CN_COMPONENTS=os,pip,npm,go,docker
#
# Docker registry mirrors. Only written when explicitly provided (the script
# never hardcodes public mirror addresses). Repeatable on the CLI with
# --docker-mirror=URL; comma-separated here.
#WEBKVM_CN_DOCKER_MIRROR=https://docker.m.daocloud.io
#
# Only used when WEBKVM_CN_COMPONENTS includes `git`: writes a per-user git
# `insteadOf` rewrite for github.com / raw.githubusercontent.com.
#WEBKVM_CN_GITHUB_PROXY=https://ghfast.top/
#
# GitHub download accelerator prefix for release tarball / updater downloads
# (https://github.com/... and https://raw.githubusercontent.com/...). Also
# speeds up the repo clone/tarball in scripts/install-webkvm.sh.
#WEBKVM_GH_PROXY=https://ghfast.top/
#
# Direct source tarball URL (http(s):// or a local path) for
# scripts/install-webkvm.sh — useful for mirror-hosted or offline installs.
#WEBKVM_INSTALL_TARBALL_URL=https://mirror.example.com/webkvm-main.tar.gz
#
# Simulated root directory / dry-run for scripts/cn-mirrors.sh (QA use: no
# root, no real package manager, no network).
#WEBKVM_CN_ROOT=/tmp/fake-root
#WEBKVM_CN_DRY_RUN=1
